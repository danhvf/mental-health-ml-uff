# Artigo científico — template oficial adaptado

O artigo foi produzido usando o template da disciplina. O pacote LaTeX completo (incluindo figuras, `main.tex`, tabelas e referências) está disponível para download no material entregue pelo projeto.

## Overleaf

1. Crie um novo projeto usando **Upload Project** e selecione o ZIP `Artigo_UFF_Overleaf_LaTeX.zip`.
2. Compile com pdfLaTeX e BibTeX.
3. Edite `main.tex` e `referencias.bib` antes da entrega final.
4. Para regenerar tabelas após executar o notebook, rode `python artigo/atualizar_resultados.py` no pacote completo local.

**Nota:** O notebook, os dados de treinamento e a avaliação fazem parte deste repositório. O pacote editável completo do artigo e suas figuras deve ser importado separadamente no Overleaf.
